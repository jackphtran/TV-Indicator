# Pine Scripts

The repository stores ready-to-paste TradingView Pine scripts without any diff markers.

To copy a script into TradingView:

1. Open the file directly (for example `pine/htf_sfp_money_noodle_strategy.pine`).
2. Copy everything between the first and last line of the file.
3. Paste the content into a new Strategy script in the TradingView Pine editor.

If you prefer using the terminal, run:

```bash
cat pine/htf_sfp_money_noodle_strategy.pine
```

This prints the script exactly as TradingView expects, with no leading `+` characters.
